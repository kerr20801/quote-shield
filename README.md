🛡 quote-shield

報價單發送前，一鍵清理敏感資訊。純瀏覽器執行，資料不離開你的電腦。

▶ 立即使用  ·  不需安裝  ·  不需登入  ·  完全免費

是什麼
業務在發報價單前，常常需要手動刪掉成本、利潤、內部備註等不該給客戶看到的資訊——這件事既耗時又容易出錯。
quote-shield 讓你上傳報價檔案，選好要遮蔽的內容，預覽確認後直接下載乾淨版本，整個流程不超過一分鐘。

功能

XLSX / CSV / PDF 格式支援
欄位型 + 敘述型報價單都能處理

有標準欄位標題 → 自動比對欄位名稱遮蔽整欄
敘述型（無結構）→ 直接掃儲存格內容，抓出金額格式自動遮蔽


四種發送對象預設：客戶 / 內部分享 / 合作夥伴 / 自訂
六種遮蔽類型：客戶名稱、報價金額、成本利潤、內部備註、供應商資訊、業務員資訊
額外關鍵字：手動加入任意文字，全文搜尋遮蔽
三視角預覽：遮蔽後 / 原始 / 對照並排
自訂存檔後綴：加日期、加時間、加對象名稱、自訂文字
密碼保護：XLSX 工作表保護 / PDF 機密標記


隱私
所有處理都在你的瀏覽器本機完成，檔案不會上傳到任何伺服器。

無後端、無資料庫、無 Cookie、無追蹤
離線也能使用（首次開啟需載入函式庫，之後可完全斷線）
原始碼完全公開，歡迎自行審查


使用方式

開啟網頁，上傳報價檔案（.xlsx / .xls / .csv / .pdf）
選擇發送對象（決定預設遮蔽哪些欄位）
細調遮蔽設定，加入額外關鍵字
設定存檔後綴與密碼（選填）
預覽確認 → 下載


支援的金額格式
自動偵測以下格式並遮蔽：
格式範例貨幣符號 + 數字$2,720,380 · NT$48,000 · ¥980,000千分位數字1,234,567純數字欄位整欄為數字且欄位名含金額關鍵字

技術棧

PDF.js — PDF 預覽
pdf-lib — PDF 處理與輸出
