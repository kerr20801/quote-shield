# PDF 遮罩一致性測試

搭配 `fix/pdf-redaction-consistency` 分支使用。目的是驗證
**「預覽看到的遮罩」與「下載檔裡的遮罩」完全一致**。

## 測試檔：`quote-shield-testcase.pdf`

四頁，每頁針對一個已知缺陷：

| 頁 | 內容 | 驗證目標 | 舊版行為 |
|---|---|---|---|
| P1 | 直立，3 個命中項 | 基準線 | 正常 |
| P2 | **旋轉 90°**，3 個命中項 | 旋轉頁座標 | ❌ 零面積框＝等於沒遮 |
| P3 | **旋轉 270°**，3 個命中項 | 旋轉頁座標 | ❌ 同上 |
| P4 | **純圖片、無文字層**，3 個命中項 | OCR 是否寫進下載 | ❌ 預覽有遮、**下載檔全裸** |

每頁另有一行 `gypsy quaggy jumpy`，用來看遮罩是否蓋到基線下伸部（g/y/p）。

命中項為 email / 電話 / 身分證號格式各一。

## 步驟

1. 開啟本分支的 `quote-shield.html`
2. 上傳 `quote-shield-testcase.pdf`
3. **務必勾選「啟用 OCR 圖片辨識」**（否則測不到 P4，那正是最嚴重的缺陷）
4. 檢查預覽：四頁應各有 3 條黑槓
5. 下載 PDF
6. **逐頁比對下載檔與預覽**——數量與位置都要一致

## 判定

- ✅ 通過：四頁的黑槓數量、位置都與預覽相同；P4 的三行資料在下載檔中不可見
- ❌ 失敗：任何一頁數量對不上，或 P4 的 email / 電話 / 身分證號在下載檔中看得到

## 對照組

用 `main` 分支跑同一份檔案，P2 / P3 / P4 應該會出問題——
可直接看出修補前後的差異。
